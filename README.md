# Cursor Unlocker Tool 🖱️

**Easily reset your Cursor AI account to regain 150 prompts!**  
This simple utility resets your machine ID and helps you get a fresh start with Cursor after hitting your limit.

---

## ❓ What is Cursor?

[Cursor](https://www.cursor.sh) is an AI-powered code editor that provides up to 150 prompts for free users. Once the limit is reached, this tool helps you reset the device ID so you can start fresh with a new account.

---

## 🚀 Features

- Reset Cursor's machine ID with one click
- No need to manually delete installed files from your system
- Beginner-friendly — no technical skills required

---

## 💻 System Requirements

- **OS:** Windows 10 or later (64-bit)
- **Permissions:** Admin rights may be required for machine ID reset
- **Internet:** Required to create or log into a new Cursor account

---

## 📥 How to Use

> 💡 Make sure Cursor is completely closed before starting.

### Step-by-Step:

1. **Uninstall Cursor**  
   (No need to remove files from `C:\` directory manually)

2. **Run Cursor Unlocker**  
   - Open the application  
   - Click **Reset Machine ID and Restart**  
   - Restart your computer when prompted

3. **Reinstall Cursor**

4. **Clear Browser Data**  
   - Clear cache, cookies, and saved data from the browser you’ll use to create/log in to Cursor

5. **Create a New Cursor Account**  
   - ⚠️ Avoid temporary email providers (they are often detected)  
   - ✅ Prefer Gmail or other trusted providers

6. **Login to Cursor**  
   - You will now receive **150 new prompts** 🎉
